## Workflow
1. QA agent triages findings and severity.
2. Spec is created and approved.
3. Backend and frontend implementation plans are finalized.
4. Fixes are implemented and tested.
5. Cross-agent code review is completed.
6. Integration gate signs off or blocks release.
